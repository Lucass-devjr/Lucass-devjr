## `03 // WHAT I'M BUILDING`

> **Nova Connect** — A full B2B platform for an automotive accessories distributor.
> Built from scratch to replace a legacy WordPress portal.

- 🚗 **Frotas Module** — Fleet order management with n8n automation (Localiza, Barigui)
- 💰 **Comissões** — Commission tracking with relational price tables & dynamic discounts
- 📦 **Products Catalog** — UNO ERP integration, bulk import, weight/dimension sync
- 🔐 **CompanyRole** — Per-company permission system with fine-grained access control
- 📊 **Analytics Dashboard** — Charts, pizza filters, financial summaries
